# Power BI Dashboard Build Guide

This repository includes Power BI-ready CSV outputs generated by `python/analyze.py`.
Power BI Desktop is required to create and save a `.pbix` file; this project does not include a fabricated PBIX file.

## 1. Generate the files
From the project root:
```bash
pip install -r requirements.txt
python python/analyze.py
```
The `outputs/` folder will contain `order_detail.csv`, `customer_summary.csv`, `item_summary.csv`, `monthly_revenue.csv`, and `membership_summary.csv`.

## 2. Import data
In Power BI Desktop, choose **Get data > Text/CSV** and import:
- `outputs/order_detail.csv`
- `outputs/customer_summary.csv`
- `outputs/item_summary.csv`
- `outputs/monthly_revenue.csv`
- `outputs/membership_summary.csv`

Set `order_date`, `first_order`, and `last_order` to Date; `price`, `revenue`, and `total_spent` to Decimal/Currency; item and visit counts to Whole number.

## 3. Suggested one-page report
- KPI cards: Total Revenue, Total Items Sold, Unique Customers, Total Visit Days.
- Clustered bar chart: `item_summary` — Axis `product_name`, Values `items_sold`.
- Line chart: `monthly_revenue` — Axis `month`, Values `revenue`.
- Bar chart: `customer_summary` — Axis `customer_id`, Values `total_spent`.
- Table: customer, total spent, items purchased, visit days.
- Donut chart: `membership_summary` — Legend `membership_status`, Values `items`.
- Add slicers for `order_date`, `product_name`, and `customer_id` if using `order_detail.csv`.

## 4. Suggested DAX measures (when using order_detail)
```DAX
Total Revenue = SUM(order_detail[price])
Items Sold = COUNTROWS(order_detail)
Unique Customers = DISTINCTCOUNT(order_detail[customer_id])
Visit Days = DISTINCTCOUNT(order_detail[order_date])
Average Revenue per Item = DIVIDE([Total Revenue], [Items Sold])
```
For visit days, the measure above counts distinct dates across the entire selected dataset, not the sum of each customer's visit days. To show visits per customer, use the `customer_summary` table.

## 5. Important interpretation note
Membership comparisons are descriptive, not proof that membership caused more purchases. This sample is small and covers only January–February 2021.
